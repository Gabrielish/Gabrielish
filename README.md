### 🌟 The Story Behind Polyhedron

It all started with a passion project: **translating *Baldur's Gate 3* into Romanian**. 

Faced with massive dialog trees and thousands of complex game strings, I built **Polyhedron** to streamline and automate the localization workflow. What began as a custom internal utility quickly evolved into a fully-featured, high-performance web & desktop tool. 

🚀 **The Vision:** Expanding Polyhedron beyond BG3 to support localization and string management for multiple major game engines and RPGs!
